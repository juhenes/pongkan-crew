# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise, contact the repository maintainers privately through a contact method listed on their GitHub profile and ask for a secure reporting channel. Do not include credentials or personal crew state in a report.

There is no guaranteed response time while this project has no stated security support commitment. If you cannot find a private contact route, avoid posting exploit details publicly.

## Supported versions

Security fixes are intended for the latest published version. No separate long-term support branches are currently promised.
